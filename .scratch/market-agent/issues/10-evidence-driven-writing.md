# 10: 证据驱动写作（有效结论·上标引用·待审附录）

**What to build:** 报告写作接入裁决结果：写作上下文只由有效结论（采纳、交叉验证通过）对应的证据组成；正文中每个数据点带 [序号] 上标，并在产物中提供 [序号] ↔ 证据组/条目 的映射；待审证据默认列入报告附录（可配置关闭），让领导知道哪些数据被排除。调研跑完即得到"每个数字都经过验证且可双向定位"的报告。

**Blocked by:** 07（聚类与裁决基线）

**Status:** ready-for-agent

- [ ] 正文中的每个数据点都来自有效结论；待审数据不出现在正文
- [ ] 数据点带 [序号] 上标；编号与产物映射一致（可由序号找到证据组与来源 URL）
- [ ] 待审清单默认出现在报告附录；配置关闭后不出现
- [ ] 有效结论为空时报告给出"证据不足"的明确提示，不编造内容
- [ ] 报告 Markdown 内含脚注定义（作为 Word 真脚注的消费契约）
- [ ] 开关关闭时报告行为与现状一致（回归）
