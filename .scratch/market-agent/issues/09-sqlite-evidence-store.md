# 09: SQLite 证据库（系统之记录）

**What to build:** 证据从内存/文件升级为可查询的单文件 SQLite 证据库：每次调研把运行、来源档案、证据条目、证据组、裁决结论写入库；证据产物（JSON + Markdown）由库导出，下载链路与格式契约不变；schema 带版本与轻量迁移约定；同一 URL + 原文引用的证据跨运行命中缓存、不重复抽取。报告存储（reports.json）等既有存储不动。

**Blocked by:** 07（聚类与裁决基线）

**Status:** ready-for-agent

- [ ] 一次调研结束后，运行/来源/证据/证据组/裁决均可从库中查询，且与导出的产物内容一致
- [ ] 产物 JSON + Markdown 由库导出，下载路径与 schema v2 契约不变
- [ ] schema 版本可查询；旧版本库按约定迁移且不丢历史
- [ ] 重复运行同一查询追加新运行、不覆盖历史
- [ ] 同一 URL + 原文引用的证据在后续调研中命中缓存、不重复抽取（可观察省下的调用与成本）
- [ ] 既有报告存储与相关行为不受影响（回归）
- [ ] 迁移与存储测试在临时库上离线运行
