# 07: 聚类与裁决基线（证据组·基础裁决）

**What to build:** 调研产生的证据条目自动归并为证据组并给出基础裁决，形成"证据驱动报告"的第一块基石。裁决策略表（各级所需独立来源条数、数值相对容差、裁定顺序）随包发布、可被业务覆盖；同一指标（实体、指标、期间、地域、单位相同）且口径一致（口径文本一致或双方均无口径）的跨来源条目归入同一证据组，口径文本不同的条目拆为不同组；组内数值在容差内视为一致，按来源等级门槛给出裁决结论（达到门槛为采纳/交叉验证通过，不足为待审）；代表值取等级最高且最新者。证据产物升级为 schema v2（含证据组、裁决结论与扩展摘要），真实调研跑完即可抽查。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 裁决策略表随包发布、默认生效，可被配置路径覆盖；文件缺失或非法时有明确报错或保守回退
- [ ] 同一指标（实体+指标+期间+地域+单位相同）且口径一致的跨来源条目归入同一证据组；口径文本不同的条目拆为不同组
- [ ] 组内数值在相对容差（策略表默认 ±5%）内视为一致；多来源一致时按等级门槛（A/B=1、B 可配、C=2、D=3）得出采纳/交叉验证通过
- [ ] 独立来源数未达门槛的组标记为待审（证据不足）；本工单独立来源先按不同域名计（主体去重与转载归并由 08 完善）
- [ ] 代表值取等级最高且最新者；证据产物为 schema v2，含证据组、裁决结论与扩展摘要（组数/各级统计/待审数）
- [ ] 裁决开关默认关闭；关闭时现有行为与产物零变化（回归）
- [ ] 全部测试离线运行（LLM 以假实现注入，网络熔断生效）
