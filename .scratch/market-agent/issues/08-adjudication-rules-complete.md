# 08: 裁决规则完善（同义归并·独立性·冲突裁定）

**What to build:** 在基线之上补齐可信度规则，让低等级来源的交叉验证真正站得住。指标同义表述（如"销量/销售量"）经 LLM 结构化判定归入同一证据组；统计口径经 LLM 判定（一致/兼容/不同），"不同"一律拆组，判定结果缓存并留痕；参与交叉验证的来源按发布主体去重（同一主体多个域名只计一条），转载（有明确来源标注或原文引用高度相似）归并为一条、判定存疑按"不算独立"处理、归并依据可查；数值超容差时按等级→时效裁定，无法裁定进入待审；文本型事实近义合并后按等级裁决，语义冲突（如"已完成"vs"计划中"）进入待审。

**Blocked by:** 07（聚类与裁决基线）

**Status:** done

- [ ] 指标同义表述自动归入同一证据组；归并判定结果与依据可在产物/库中查到
- [ ] 口径判定为"不同"的条目一律拆组；判定结果缓存，同一输入不重复消耗 LLM 调用
- [ ] 同一发布主体的多个域名只计一条独立来源；转载归并为一条并记录依据；判定存疑时不算独立（保守）
- [ ] 数值超容差按等级→时效裁定；等级互斥（如两条 A 级矛盾）等无法裁定场景进入待审
- [ ] 文本型事实近义合并、语义冲突进入待审
- [ ] 全部判定（归并/转载/裁定）留有可复核记录；测试离线、LLM 假实现注入
