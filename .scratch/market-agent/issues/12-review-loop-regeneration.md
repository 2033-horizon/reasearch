# 12: 复核闭环（处置·重生成·进度入口）

**What to build:** 只处理例外项的复核闭环：调研结束后可打开复核页面查看待审证据组（各来源并排对比等级/主体/数值/口径/引用/URL），做采纳、否决或指定主来源；处置记录复核人与时间并合成有效结论；处置后可重生成报告（只重跑写作阶段），新版本文件产出、旧版保留、版本入库；调研过程中实时可见聚类与裁决进度，结束事件带复核入口。

**Blocked by:** 09（SQLite 证据库）、10（证据驱动写作）

**Status:** ready-for-agent

- [ ] 复核页面只列待审证据组，每个组能看到全部来源的等级/主体/数值/口径/引用/URL 对比
- [ ] 采纳/否决/指定主来源三个动作生效并写库，记录复核人与时间
- [ ] 复核合成有效结论：重生成后，采纳的待审数据进入正文、否决的不出现
- [ ] 重生成只重跑写作阶段（不重新检索抓取）；新版本文件产出、旧版保留、版本记录可查
- [ ] 调研过程实时可见聚类/裁决进度与待审统计；结束事件包含复核入口链接
- [ ] 复核结论仅本次调研内生效，不跨调研复用
- [ ] 接口测试离线运行（TestClient，LLM 假实现）
