# 来源等级：规则即数据，LLM 兜底最高 C，未知默认 D

- 状态：accepted
- 日期：2026-09-29

## 决策

来源等级（A-D）由外部规则表（YAML 数据文件，`RELIABILITY_RULES_PATH` 可覆盖）判定。优先级：`domain_exact` > `suffix`（最长后缀胜）> LLM 兜底 > 默认 D。LLM 兜底最高只能判 C；A/B 必须由规则命中。LLM 判定结果持久化缓存（`TIER_CACHE_PATH`）作为候选规则池，定期人工提拔进规则表。

## 原因

领导对权威来源的信任必须建立在确定性、可审计、可复现之上。规则表让业务可以自行维护白名单而无需改代码；LLM 只能处理未知域名，且不能把不可信来源抬到高等级。

## 考虑过的方案

- **代码内字典**：业务维护门槛高，白名单演进频繁时不现实。
- **纯 LLM 打分**：不可审计、不可复现，等级不可解释。

## 后果

- 规则表与缓存文件成为需要版本管理和运维的运行态资产。
- 白名单初版由开发起草、业务确认后生效。
