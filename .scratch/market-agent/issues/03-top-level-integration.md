# 03: 顶层接入：自动触发与子研究者抑制

**What to build:** 证据层由顶层研究者在研究完成时自动触发，配置开关控制且默认关闭；子研究者（deep 子查询、detailed 子主题）不触发；deep 路径在子研究来源聚合后仍触发且覆盖全部来源。目的是让所有入口（WebSocket/HTTP/CLI）自动获得证据产物，不依赖调用方记得调用。

**Blocked by:** 02（证据抽取通路）

**Status:** ready-for-agent

- [ ] 配置开关默认关闭；关闭时现有行为与测试零变化（回归验证通过）
- [ ] 开启时，顶层研究者完成研究后自动产出证据产物，产物路径可从研究者对象获取
- [ ] 子研究者（deep 子查询、detailed 子主题创建的嵌套实例）不触发证据层
- [ ] deep 路径：子研究来源聚合后仍触发，产物覆盖全部子研究来源
- [ ] 测试以假 LLM/假来源覆盖以上四条行为；顶层两个返回路径（deep 分支与常规分支）均被覆盖
