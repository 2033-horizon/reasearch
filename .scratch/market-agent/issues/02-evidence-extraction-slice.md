# 02: 证据抽取通路（证据条目 + 原文引用校验）

**What to build:** 在证据产物中加入证据条目：从含正文的来源抽取结构化数据（指标、数值、原文写法、单位、期间、口径、主体），每条必须携带能在正文中逐字定位的原文引用；校验失败先纠正一次，仍失败则丢弃并记入 rejected。同一来源内重复数据去重，跨来源重复保留。

**Blocked by:** 01（来源分级通路）

**Status:** done

- [x] 含正文来源经抽取后，产物 evidence 数组有条目且字段完整：指标、数值（原文写法 + 归一化值）、单位、期间、口径、原文引用、来源标识；主体有则记录
- [x] 支持四种取值类型：number / range / ratio / text（区间与文本型事实同样可记录）
- [x] 原文引用校验：空白/换行/全半角/NFKC 变体均可命中；编造引用被拒绝并进 rejected[]，带原因
- [x] 校验失败先按原文纠正一次，仍失败才丢弃；无模糊匹配、不保留未验证条目（fail-closed）
- [x] 脏 JSON 容错解析（fenced/带散文/字段缺失）；彻底解析失败进 rejected[]
- [x] 同一来源内相同数据（指标+数值+期间）去重；跨来源重复保留
- [x] 无正文或正文 <300 字符的来源不抽取，仅保留来源档案
- [x] 分块与并发参数生效：每来源截断 30k 字符、块 8k/重叠 400、并发 4；跳过与上限均可配置
- [x] 抽取阶段的 LLM 成本计入现有成本统计
- [x] 全部测试离线运行（LLM 以假实现注入）
