# 原文引用 fail-closed：不能逐字定位就丢弃

- 状态：accepted
- 日期：2026-09-29

## 决策

每条证据条目必须携带原文引用（Quote）。校验方式：双方 NFKC 归一化 + 空白折叠后做严格子串匹配；失败时让 LLM 按原文纠正一次，仍失败则丢弃该条目并记入产物的 `rejected[]`，不进入证据集。

## 原因

防编造是本项目的信用基础——领导采用报告的前提是"数据可溯源、非编造"。宁可损失召回率，也不让未验证数据静默流入下游。

## 考虑过的方案

- **保留并标记 `quote_verified=false`**：未验证条目会随报告流程静默流入下游。
- **模糊匹配（编辑距离阈值）**：为编造留下可乘之机，违背 fail-closed 原则。

## 后果

- 表格类、分页类内容的召回会下降（表格改 markdown 记入 backlog）。
- `rejected[]` 日志可用于迭代抽取 prompt。
