# 01: 来源分级通路（证据产物·分级版）

**What to build:** 给定一批来源，产出分级版证据产物：每个来源生成来源档案（来源等级 A-D、发布主体、判定方式、命中规则），产物含 summary 统计（来源数、各等级计数），JSON 与 Markdown 双格式落盘。规则表以数据文件维护、优先级可解释，未知域名由 LLM 兜底且等级保守。完成后业务即可开始审阅白名单初版。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 给定含已知政府/机构/媒体/自媒体/未知域名 fixture 来源列表，产出证据产物：每个来源生成来源档案，来源等级、发布主体、判定方式（rule/llm/default）、命中规则均正确
- [ ] 产物 JSON 带 schema_version 与 summary（来源数、scraped 数、by_tier 各等级计数）；Markdown 证据表可读
- [ ] 规则判定优先级正确：精确域名 > 后缀（最长后缀胜）；子域正确命中后缀规则；域名匹配前规范化（去 scheme/路径/端口，取 host）
- [ ] 未知域名：LLM 兜底最高判 C；LLM 不可用或失败时默认 D；LLM 判定标记 assigned_by 并写入等级缓存
- [ ] 同一未知域名第二次出现不再调用 LLM（缓存命中，不重复计费）
- [ ] 规则表为随包发布的 YAML，可被配置路径覆盖；打包声明包含该文件，容器/安装部署不丢文件
- [ ] 全部测试离线运行（LLM 以假实现注入，网络熔断生效）
